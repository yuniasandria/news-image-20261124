A program that draws one 1024x1024 image summing up the world news of Tuesday 24 November 2026: Nvidia brings back Jensen Huang (+31.5%), COP31 ends with no deal, Ukraine sinks a Russian warship off Libya, a factory fire in Indonesia, Democrats win the House, the World Chess Championship begins, and Trump halts the Iowa blast. Pure Python 3.13 stdlib: its own PNG encoder and a bitmap font generated at build time from local DejaVu fonts.

## Run it

```sh
python3 main.py
```
